// 01 sobre

Sobre

Trabalho no suporte técnico da Rede ICC Saúde, em Fortaleza, atendendo diretamente os setores que lidam com pacientes, incluindo os consultórios de quimioterapia. Nesse ambiente, um computador parado é um atendimento atrasado, e isso molda a forma como eu trabalho: resolver rápido e documentar para não repetir.

Fora do expediente, mantenho um laboratório doméstico que simula a infraestrutura de uma empresa, onde estudo servidores Windows e Linux, virtualização e redes, e onde rodam os sistemas que desenvolvo.

// 02 projetos

Projetos

// projeto acadêmico · equipe de 5

BarberConnect

Plataforma de agendamento para barbearias, criada para um barbeiro de bairro que controlava a agenda no papel e no WhatsApp. Começou como painel web de gestão e evoluiu para aplicativo mobile, onde o cliente escolhe serviço, profissional e horário.

Meu papel no app
Front-end mobile: início e navegação de visitante, login e cadastro, perfil do cliente com histórico de atendimentos.
Meu papel na versão web
Telas do painel, integração com a API e documentação Swagger.
  • React Native
  • TypeScript
  • React
  • Node.js
  • Supabase
  • Swagger

Sistema de contas a pagar

Aplicação web para controle de despesas, parcelas recorrentes, assinaturas e divisão de gastos, com ambientes separados de produção e homologação. Hospedada em VM Ubuntu com Nginx e banco PostgreSQL gerenciado.

  • React
  • TypeScript
  • Node.js
  • Prisma
  • PostgreSQL
  • Nginx

LAB.LOCAL

Laboratório corporativo doméstico com Domain Controller, Active Directory, DNS, GPO e servidores virtualizados em Hyper-V, usado para estudar administração de infraestrutura como numa empresa real.

  • Windows Server
  • Active Directory
  • Hyper-V
  • PowerShell

Painel NOC

Painel web de monitoramento dos servidores do laboratório: CPU, memória, armazenamento e velocidade de internet, com coleta sem agente e comandos remotos de ligar, desligar e reiniciar.

  • Python
  • FastAPI
  • WinRM
  • Wake-on-LAN

VM RHEL de estudo

Ambiente Red Hat Enterprise Linux para estudar administração Linux corporativa: firewalld, SELinux, containers com Podman e gerenciamento pelo Cockpit.

  • RHEL 9
  • SELinux
  • Podman
  • firewalld
